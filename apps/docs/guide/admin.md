# Admin Panel

The admin panel is auto-generated from your schema files. Access it at `/admin` when the dev server is running.

## Features

- **Dashboard** — overview of collections, globals, and components
- **Content management** — create, edit, delete entries for each collection
- **Global editors** — edit singleton content
- **Media library** — upload and manage media files
- **Schema viewer** — browse and edit schema definitions
- **User management** — manage admin users and roles
- **Plugin settings** — configure installed plugins

## Command Palette

Press `Cmd+K` (Mac) / `Ctrl+K` (Windows/Linux) to open the command palette for quick navigation.

## Rich Text Editor

Rich text fields use Tiptap with support for:
- Bold, italic, underline, strikethrough
- Headings (H1-H3)
- Lists (ordered, bullet)
- Blockquotes
- Code blocks
- Undo/redo

## Code Editor

Code fields use CodeMirror 6 with syntax highlighting for JavaScript, TypeScript, JSX, TSX, JSON, CSS, HTML, Markdown, and XML.

## Media Upload

Drag and drop or click to upload images and files. Uploaded media is available across all media fields.
